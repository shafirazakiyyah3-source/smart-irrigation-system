# smart-irrigation-system


## Deskripsi
Proyek Smart Garden berbasis ESP32 untuk memonitor dan mengontrol kondisi tanaman secara real-time.

## Fitur
- Monitoring suhu (DHT21)
- Monitoring kelembapan udara
- Monitoring kelembapan tanah
- Kontrol kipas
- Kontrol pompa
- Dashboard Web
- ThingSpeak Monitoring
- LCD 20x4

## Hardware
- ESP32
- DHT21
- Soil Moisture Sensor
- Relay Module
- LCD I2C 20x4

## Software
- Arduino IDE
- LittleFS
- ThingSpeak
- HTML, CSS, JavaScript

## Library
- WiFi
- ESPAsyncWebServer
- LittleFS
- DHT
- LiquidCrystal_I2C
- ThingSpeak
- ArduinoJson
